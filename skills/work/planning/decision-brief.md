# Decision brief

Compare options in a short decision brief with evidence, trade-offs and a recommendation.

1. State the decision, intended decision maker, deadline if supplied and the criteria that matter.
2. Compare each viable option against those criteria. Attribute material claims to a supplied source and mark assumptions where evidence is missing.
3. Recommend an option only when the evidence supports it. Include the strongest reason to choose another option and the next reversible step. Return the brief in a form a reviewer can read in one sitting.
