# Meeting actions

Turn meeting notes into agreed actions, owners, deadlines and open questions.

1. Read the supplied notes. Separate decisions already made from suggestions and unresolved questions.
2. For each agreed action, write one verb-led task and quote or point to the note that supports it. Carry over the named owner and due date. Use “unassigned” or “date to confirm” when either is missing.
3. Return a short decisions list, an action table, and only the questions that block a next step. Check every name and date against the notes before sharing.
