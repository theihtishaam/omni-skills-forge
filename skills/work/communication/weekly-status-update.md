# Weekly status update

Write a weekly stakeholder update from completed work, blockers and next steps.

1. Identify the reporting period and intended reader. Group the supplied work by outcome.
2. Write what changed, why it matters, and the next planned action. Separate shipped work from planned work. Include a blocker only if it changes a decision or delivery date.
3. End with an explicit ask and owner if the source supports them. Check dates and links against the input. Omit invented metrics and commitments.
